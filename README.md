# Подбор хороших вин. Демо на Streamlit

## Запуск

Python 3.13.

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Кэширование

`st.cache_resource` хранит один объект на весь сервер и отдаёт его без копирования, поэтому подходит для модели, которую не нужно сериализовать при каждом обращении. `st.cache_data` сериализует результат и при каждом вызове возвращает копию, поэтому подходит для таблиц и массивов, так как изменение полученных данных не испортит кэш.

Если вызывать `joblib.load` без декоратора, модель будет заново читаться с диска при каждом перезапуске скрипта, то есть при любом действии пользователя, например при сдвиге слайдера.
